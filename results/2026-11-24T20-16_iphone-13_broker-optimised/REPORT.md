## What the rows mean

- **Frames per second:** 60 is perfectly smooth on a 60 Hz screen. Frames are drawn only when data changes, so a very quiet feed can show fewer frames without anything being wrong.
- **Frames that missed the deadline:** took longer than one screen refresh (16.7 ms at 60 Hz) on the UI or GPU thread.
- **UI thread still busy when a frame was due:** time the frame had to wait. Decoding on the UI thread shows up here.
- **Background isolate CPU:** present when decoding runs off the UI thread. It is the JSON or Protobuf cost moved to another core.
- **Tick age when shown:** from the message arriving to the frame that shows it.
